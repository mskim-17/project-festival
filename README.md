# 🎆 축!

축제를 즐기고 싶은 사람부터 행사를 함께 만들어갈 사람까지 축제를 사랑하는 모든 이들을 위한 축제 구인·구직 웹 사이트. 개최가 확정된 전국의 다양한 축제 정보를 제공하는 한편, 기업은 축제를 성공적으로 개최하기 위한 인력과 서비스를 모집하고, 구직자는 원하는 축제의 공고에 지원해 하나하나의 축제를 성공적으로 개최하기 위한 **축제 종합 플랫폼**의 역할을 합니다.

----
## ⚙️ 개발 도구 및 기술 스택
- **Frontend**: Thymeleaf
- **Backend**: Spring Boot, Spring Security
- **Database**: MySQL, JPA, QueryDSL
